# 07. 删除购物车项

`DELETE /api/cart-items/{productId}`

## 一句话说明
把购物车里的某一项删掉。

## 什么时候会用到
用户在**结算页**点了 "Delete"（前端会先弹个框问"确定删吗"，确定后才调这个接口）。

## 前端会传什么给你

| 参数 | 意思 |
| --- | --- |
| `productId` | 要删哪一项（路径里） |

例子：`DELETE /api/cart-items/3ebe75dc-64d2-4137-8860-1f5a963e534b`

## 你要返回什么（响应，状态码 204）
204 表示"成功了，但没有内容要返回"。所以**响应体是空的**，不用返回任何 JSON。

## 后端要做的事（业务规则）
1. 这一项得存在，不存在返回 404。
2. 删掉，返回 204。

## SQL 怎么写
```sql
DELETE FROM cart_item WHERE product_id = :productId;
```

## 可能出错的情况
| 情况 | 怎么办 |
| --- | --- |
| 这一项不存在 | 404，`code=CART_ITEM_NOT_FOUND` |
| 删完购物车空了 | 正常；前端结算页会显示 "The cart is empty" |

## 会用到哪些表
`cart_item`

## 名词解释 / 提醒
- **DELETE**：用来"删除数据"的请求方式。
- **204**：一种成功状态码，专门用于"操作成功但没东西返回"的场景，比如删除。
- 同 06，以后支持一个商品多型号时，建议改用 `cart_item.id` 定位。
