## 🔗 前端如何连接后端

### 1. Vite 代理配置（关键）

**文件位置**：`e:\react-course\ecommerce-project\vite.config.ts`

```typescript
export default defineConfig({
  plugins: [react()],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:3000'  // ← 指向 Spring Boot 后端
      },
      '/images': {
        target: 'http://localhost:3000'  // ← 图片也从后端获取
      }
    }
  }
})
```

**工作原理**：

当前端发起请求 `/api/products` 时：

```
1. 浏览器发送：http://localhost:5173/api/products
   ↓
2. Vite 拦截请求，看到 /api 前缀
   ↓
3. Vite 转发到：http://localhost:3000/api/products
   ↓
4. Spring Boot 后端接收并处理
   ↓
5. 返回 JSON 数据给 Vite
   ↓
6. Vite 转发给浏览器
```

**为什么需要代理？**

- **避免跨域问题**：前端（5173）和后端（3000）端口不同，浏览器会阻止跨域请求
- **统一路径**：前端只需使用 `/api/products`，不需要写完整 URL

### 2. 前端 API 调用

**文件位置**：`e:\react-course\ecommerce-project\src\api\productsApi.ts`

```typescript
import axios from "axios";
import { ENDPOINTS } from "./endpoints";

// 获取商品列表
export async function fetchProducts(): Promise<ProductType[]> {
  // 实际请求：http://localhost:5173/api/products
  // 被代理到：http://localhost:3000/api/products
  const response = await axios.get<ProductType[]>(ENDPOINTS.PRODUCTS);
  return response.data;
}
```

**API 端点配置**：

  // ...

### 3. 后端 API 接口

**Spring Boot 后端地址**：`E:\java\spring-boot-ecommerce`

#### Controller 层（接收请求）

**文件位置**：`ecommerce-web/src/main/java/com/ecommerce/web/controller/ProductController.java`

```java
@RestController
@RequestMapping("/api/products")
public class ProductController {
    
    @GetMapping  // 处理 GET /api/products
    public ResponseEntity<List<ProductResponse>> getAllProducts(
        @RequestParam(required = false) String search
    ) {
        List<ProductResponse> products = productService.getAllProducts(search);
        return ResponseEntity.ok(products);
    }
    
    @GetMapping("/{id}")  // 处理 GET /api/products/{id}
    public ResponseEntity<ProductResponse> getProductById(@PathVariable String id) {
        ProductResponse product = productService.getProductById(id);
        return ResponseEntity.ok(product);
    }
}
```

#### Service 层（业务逻辑）

**文件位置**：`ecommerce-service/src/main/java/com/ecommerce/service/ProductService.java`

```java
@Service
public class ProductService {
    
    public List<ProductResponse> getAllProducts(String search) {
        // 1. 从数据库查询商品
        List<Product> products;
        if (search != null) {
            products = productMapper.searchByKeyword(search);
        } else {
            products = productMapper.selectList(null);
        }
        
        // 2. 转换为 DTO 返回给前端
        return products.stream()
            .map(this::convertToResponse)
            .collect(Collectors.toList());
    }
}
```

#### Mapper 层（数据库操作）

**文件位置**：`ecommerce-dao/src/main/java/com/ecommerce/dao/mapper/ProductMapper.java`

```java
@Mapper
public interface ProductMapper extends BaseMapper<Product> {
    
    // MyBatis-Plus 提供的方法：
    // - selectList(null) → SELECT * FROM products
    // - selectById(id) → SELECT * FROM products WHERE id = ?
    
    // 自定义查询方法
    default List<Product> searchByKeyword(String keyword) {
        LambdaQueryWrapper<Product> wrapper = new LambdaQueryWrapper<>();
        wrapper.like(Product::getName, keyword)
               .or()
               .apply("FIND_IN_SET({0}, keywords)", keyword);
        return selectList(wrapper);
    }
}
```

## ❗ 常见连接问题

### 问题 1：前端显示白屏，控制台报错

**错误信息**：

```
GET http://localhost:5173/api/products net::ERR_CONNECTION_REFUSED
```

**原因**：后端没有启动

**解决方法**：

1. 检查 Spring Boot 是否在运行
2. 检查端口 3000 是否被占用
3. 查看后端控制台是否有错误

---

### 问题 2：前端报错 CORS

**错误信息**：

```
Access to XMLHttpRequest at 'http://localhost:3000/api/products' 
from origin 'http://localhost:5173' has been blocked by CORS policy
```

**原因**：CORS 配置问题（但你的后端应该已经配置好了）

**解决方法**：

检查 `CorsConfig.java` 是否存在：

文件：`ecommerce-web/src/main/java/com/ecommerce/web/config/CorsConfig.java`

```java
@Configuration
public class CorsConfig {
    @Bean
    public CorsFilter corsFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowedOrigins(Arrays.asList(
            "http://localhost:5173",  // ← 允许前端访问
            "http://localhost:3000"
        ));
        config.setAllowedMethods(Arrays.asList("GET", "POST", "PUT", "DELETE"));
        config.setAllowCredentials(true);
        // ...
    }
}
```

---

### 问题 3：前端显示 404

**错误信息**：

```
GET http://localhost:5173/api/products 404 (Not Found)
```

**原因**：后端路由不存在或路径错误

**解决方法**：

1. 确认后端 Controller 的 `@RequestMapping("/api/products")` 是否正确
2. 检查前端请求路径是否拼写正确
3. 直接访问 http://localhost:3000/api/products 测试后端

---

### 问题 4：数据返回格式不对

**错误信息**：

```
TypeError: Cannot read property 'rating' of undefined
```

**原因**：后端返回的数据格式与前端期望不一致

**解决方法**：

1. 在浏览器 Network 标签查看实际返回的数据
2. 对比 TypeScript 类型定义：

```typescript
// src/types.ts
export interface ProductType {
  id: string;
  image: string;
  name: string;
  rating: {
    stars: number;
    count: number;
  };
  priceCents: number;
  keywords?: string[];
}
```

3. 检查后端 DTO 是否匹配：

```java
// ProductResponse.java
public class ProductResponse {
    private String id;
    private String name;
    private String image;
    private Integer priceCents;
    private RatingResponse rating;  // ← 嵌套对象
    private List<String> keywords;
}
```

## 🎯 总结

### 连接关系

```
前端 (5173) ←─ Vite 代理 ─→ 后端 (3000) ←─ MyBatis-Plus ─→ MySQL
```

### 关键配置

1. **前端代理**：`vite.config.ts` 中的 `proxy` 配置
2. **后端 CORS**：`CorsConfig.java` 允许跨域
3. **API 路径**：前后端统一使用 `/api` 前缀

### 启动顺序

1. ✅ 先启动 MySQL 数据库
2. ✅ 再启动 Spring Boot 后端（端口 3000）
3. ✅ 最后启动 Vite 前端（端口 5173）

- 浏览器 F12 → Network 标签
- 直接访问后端：http://localhost:3000/api/products
