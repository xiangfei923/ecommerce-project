## 功能概述

### 商品列表功能
- **首页展示**：展示所有商品的网格布局
- **商品卡片**：包含图片、名称、评分、价格、加购物车按钮
- **懒加载**：图片使用 `loading="lazy"` 优化加载性能

### 商品搜索功能
- **搜索框**：顶部 Header 中的搜索输入框
- **实时搜索**：输入关键词后提交跳转到搜索页面
- **模糊匹配**：支持商品名称和关键词的大小写不敏感匹配
- **URL 参数**：搜索词保存在 URL 的 `q` 参数中（如 `/search?q=shirt`）

## 数据库设计

### 表结构设计

#### 1. products 表（商品表）
```sql
CREATE TABLE products (
  id VARCHAR(50) PRIMARY KEY,                    -- 商品唯一标识
  name VARCHAR(255) NOT NULL,                    -- 商品名称
  image VARCHAR(500) NOT NULL,                   -- 商品图片路径
  price_cents INT NOT NULL,                      -- 价格（分为单位）
  rating_stars DECIMAL(2,1) NOT NULL,            -- 评分（0.0-5.0）
  rating_count INT NOT NULL DEFAULT 0,           -- 评分人数
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  INDEX idx_name (name),                         -- 商品名称索引（搜索优化）
  INDEX idx_price (price_cents),                 -- 价格索引（排序优化）
  INDEX idx_rating (rating_stars)                -- 评分索引（排序优化）
);
```

#### 2. product_keywords 表（商品关键词表）
```sql
CREATE TABLE product_keywords (
  id INT AUTO_INCREMENT PRIMARY KEY,
  product_id VARCHAR(50) NOT NULL,              -- 关联商品ID
  keyword VARCHAR(100) NOT NULL,                -- 关键词
  
  FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
  INDEX idx_keyword (keyword),                  -- 关键词索引（搜索优化）
  INDEX idx_product_keyword (product_id, keyword)
);
```

```javascript
// models/Product.js
const db = require('../db');

class Product {
  // 获取所有商品及其关键词
  static async findAll() {
    const query = `
      SELECT 
        p.id,
        p.name,
        p.image,
        p.price_cents as priceCents,
        p.rating_stars as ratingStars,
        p.rating_count as ratingCount,
        GROUP_CONCAT(pk.keyword) as keywords
      FROM products p
      LEFT JOIN product_keywords pk ON p.id = pk.product_id
      GROUP BY p.id
      ORDER BY p.created_at DESC
    `;
    
    const [rows] = await db.query(query);
    
    // 转换数据格式
    return rows.map(row => ({
      id: row.id,
      name: row.name,
      image: row.image,
      priceCents: row.priceCents,
      rating: {
        stars: parseFloat(row.ratingStars),
        count: row.ratingCount
      },
      keywords: row.keywords ? row.keywords.split(',') : []
    }));
  }

  // 根据ID获取单个商品
  static async findById(id) {
    const query = `
      SELECT 
        p.id,
        p.name,
        p.image,
        p.price_cents as priceCents,
        p.rating_stars as ratingStars,
        p.rating_count as ratingCount,
        GROUP_CONCAT(pk.keyword) as keywords
      FROM products p
      LEFT JOIN product_keywords pk ON p.id = pk.product_id
      WHERE p.id = ?
      GROUP BY p.id
    `;
    
    const [rows] = await db.query(query, [id]);
    
    if (rows.length === 0) return null;
    
    const row = rows[0];
    return {
      id: row.id,
      name: row.name,
      image: row.image,
      priceCents: row.priceCents,
      rating: {
        stars: parseFloat(row.ratingStars),
        count: row.ratingCount
      },
      keywords: row.keywords ? row.keywords.split(',') : []
    };
  }

  // 搜索商品（后端实现 - 性能更优）
  static async search(keyword) {
    const searchTerm = `%${keyword}%`;
    const query = `
      SELECT DISTINCT
        p.id,
        p.name,
        p.image,
        p.price_cents as priceCents,
        p.rating_stars as ratingStars,
        p.rating_count as ratingCount,
        GROUP_CONCAT(DISTINCT pk.keyword) as keywords
      FROM products p
      LEFT JOIN product_keywords pk ON p.id = pk.product_id
      WHERE p.name LIKE ? 
         OR pk.keyword LIKE ?
      GROUP BY p.id
      ORDER BY p.rating_stars DESC, p.rating_count DESC
    `;
    
    const [rows] = await db.query(query, [searchTerm, searchTerm]);
    
    return rows.map(row => ({
      id: row.id,
      name: row.name,
      image: row.image,
      priceCents: row.priceCents,
      rating: {
        stars: parseFloat(row.ratingStars),
        count: row.ratingCount
      },
      keywords: row.keywords ? row.keywords.split(',') : []
    }));
  }
}

module.exports = Product;
```

```javascript
    res.status(500).json({ error: 'Internal server error' });
  }

// 搜索商品
exports.searchProducts = async (req, res) => {
  try {
    const { q } = req.query;
    
    if (!q || q.trim() === '') {
      // 如果没有搜索词，返回所有商品
      const products = await Product.findAll();
      return res.json(products);
    }
    
    const products = await Product.search(q.trim());
    res.json(products);
  } catch (error) {
    console.error('Error searching products:', error);
    res.status(500).json({ error: 'Internal server error' });
  }
```

### 核心 SQL 语句解析

#### 1. 获取商品列表（含关键词）
```sql
SELECT 
  p.id,
  p.name,
  p.image,
  p.price_cents,
  p.rating_stars,
  p.rating_count,
  GROUP_CONCAT(pk.keyword) as keywords  -- 将多个关键词合并成字符串
FROM products p
LEFT JOIN product_keywords pk ON p.id = pk.product_id
GROUP BY p.id                           -- 按商品ID分组
ORDER BY p.created_at DESC;             -- 按创建时间倒序
```

**关键点**：
- 使用 `LEFT JOIN` 确保没有关键词的商品也能显示
- `GROUP_CONCAT` 将多行关键词合并为一个逗号分隔的字符串
- `GROUP BY p.id` 将同一商品的多个关键词聚合到一行

#### 2. 搜索商品
```sql
SELECT DISTINCT
  p.id,
  p.name,
  p.image,
  p.price_cents,
  p.rating_stars,
  p.rating_count,
  GROUP_CONCAT(DISTINCT pk.keyword) as keywords
FROM products p
LEFT JOIN product_keywords pk ON p.id = pk.product_id
WHERE p.name LIKE '%shirt%'             -- 商品名称模糊匹配
   OR pk.keyword LIKE '%shirt%'         -- 或关键词模糊匹配
GROUP BY p.id
ORDER BY p.rating_stars DESC,           -- 按评分降序
         p.rating_count DESC;           -- 评分相同时按评论数降序
```

**关键点**：
- 使用 `LIKE '%keyword%'` 实现模糊搜索
- 支持在商品名称和关键词中搜索
- 按评分和评论数排序提升用户体验

**4.2 SearchPage 组件**
```typescript
// src/pages/search/SearchPage.tsx
import { useEffect, useState } from "react";
import { useSearchParams } from "react-router";
import { Header } from "../../components/Header";
import { ProductsGrid } from "../home/ProductsGrid";
import { fetchProducts } from "../../api/productsApi";
import type { ProductType } from "../../types";
import "./SearchPage.css";

// 根据关键词匹配商品名称或 keywords 字段（大小写不敏感）
function matchesSearchTerm(product: ProductType, term: string): boolean {
  const lowerTerm = term.toLowerCase();
  
  // 检查商品名称是否包含搜索词
  const nameMatches = product.name.toLowerCase().includes(lowerTerm);
  
  // 检查关键词数组中是否有匹配项
  const keywordMatches = product.keywords?.some((keyword) =>
    keyword.toLowerCase().includes(lowerTerm)
  );
  
  return nameMatches || Boolean(keywordMatches);
}

export function SearchPage() {
  // 读取 URL 查询参数中的搜索词
  const [searchParams] = useSearchParams();
  const searchTerm = searchParams.get("q") ?? "";
  
  const [products, setProducts] = useState<ProductType[]>([]);
  const [isLoading, setIsLoading] = useState(true);

  // 获取所有商品数据
  useEffect(() => {
    let isCancelled = false;

    const getSearchResults = async () => {
      try {
        setIsLoading(true);
        const data = await fetchProducts();
        if (!isCancelled) {
          setProducts(data);
        }
      } catch (error) {
        console.error('Failed to fetch products:', error);
      } finally {
        if (!isCancelled) {
          setIsLoading(false);
        }
      }
    };

    getSearchResults();

    // 清理函数：防止组件卸载后更新状态
    return () => {
      isCancelled = true;
    };
  }, []); // 只在组件挂载时执行一次

  // 前端过滤商品
  const trimmedTerm = searchTerm.trim();
  const filteredProducts = trimmedTerm
    ? products.filter((product) => matchesSearchTerm(product, trimmedTerm))
    : products;

  return (
    <>
      <title>Search Results - Ecommerce Project</title>
      <Header />
      <div className="home-page search-page">
        {/* 搜索结果标题 */}
        <div className="search-results-heading">
          {trimmedTerm ? (
            <>
              Search results for <strong>&quot;{trimmedTerm}&quot;</strong>
            </>
          ) : (
            "All Products"
          )}
        </div>

        {/* 无结果提示 */}
        {!isLoading && filteredProducts.length === 0 && (
          <div className="no-results-message">
            No products found matching &quot;{trimmedTerm}&quot;. 
            Try a different keyword.
          </div>
        )}

        {/* 商品网格 */}
        {isLoading ? (
          <div className="loading-spinner">Loading...</div>
        ) : (
          <ProductsGrid products={filteredProducts} />
        )}
      </div>
    </>
  );
}
```

**执行流程**：
1. 组件挂载时从 URL 获取 `q` 参数（搜索词）
2. 调用 `fetchProducts()` 获取所有商品
3. 在前端使用 `matchesSearchTerm` 函数过滤商品
4. 匹配逻辑：商品名称或关键词包含搜索词（忽略大小写）
5. 将过滤后的结果传给 `ProductsGrid` 展示

## 设计原理

### 1. 为什么这样设计？

#### 前后端分离架构
**原因**：
- **解耦性**：前端和后端可以独立开发、测试、部署
- **可扩展性**：前端可以切换框架（React → Vue），后端不受影响
- **复用性**：同一套 API 可以服务 Web、移动端、桌面应用

#### RESTful API 设计
**原因**：
- **标准化**：使用 HTTP 方法（GET、POST、PUT、DELETE）表达操作语义
- **可缓存**：GET 请求可以被浏览器和 CDN 缓存
- **简单明了**：`/api/products` 比 `/getProductList` 更符合 REST 规范

#### 关键词表独立设计
**原因**：
- **规范化**：避免在 products 表中存储逗号分隔的字符串
- **灵活查询**：可以高效地按关键词搜索
- **易于维护**：添加或删除关键词不影响商品主表

#### 前端过滤 vs 后端搜索
**当前实现采用前端过滤**：
```typescript
const filteredProducts = products.filter(
  product => matchesSearchTerm(product, searchTerm)
);
```

**原因**：
- **简化后端**：不需要额外的搜索接口
- **实时响应**：切换搜索词无需重新请求
- **适用场景**：商品总数较少（< 1000）时性能可接受

**何时应该用后端搜索**：
- 商品总数 > 1000 时
- 需要复杂搜索（价格区间、多条件过滤）
- 需要搜索排序（相关度、热度）

### 2. 组件设计原则

#### 单一职责原则
- **HomePage**：负责获取数据和页面布局
- **ProductsGrid**：负责网格布局
- **Product**：负责单个商品卡片的展示和交互

#### 组件复用
- `ProductsGrid` 同时被 `HomePage` 和 `SearchPage` 使用
- 避免重复代码，提高维护性

#### 状态提升
- 商品数据存储在 `HomePage` / `SearchPage` 中
- 子组件通过 props 接收数据，保持纯函数特性

## 性能问题

### 当前架构存在的性能问题

#### 1. 前端过滤性能瓶颈
**问题**：
```typescript
// 每次搜索都要遍历所有商品
const filteredProducts = products.filter(
  product => matchesSearchTerm(product, searchTerm)
);
```

**影响**：
- 商品数量 > 1000 时，过滤操作会导致明显卡顿
- 每次输入都会重新过滤，浪费 CPU 资源

#### 2. 首屏加载慢
**问题**：
- 一次性加载所有商品数据
- 商品数量多时，HTTP 响应体积大（可能 > 1MB）

**影响**：
- 首屏白屏时间长
- 移动网络环境下体验差

#### 3. 图片未优化
**问题**：
- 虽然使用了 `loading="lazy"`，但图片尺寸可能很大
- 未使用响应式图片（`srcset`）

**影响**：
- 带宽浪费
- 渲染慢

#### 4. 无缓存机制
**问题**：
```typescript
useEffect(() => {
  const data = await fetchProducts(); // 每次都重新请求
  setProducts(data);
}, []);
```

**影响**：
- 用户在首页和搜索页之间切换时重复请求
- 服务器压力大

#### 5. SQL 查询效率低
**问题**：
```sql
-- 每次都要 JOIN 和 GROUP_CONCAT
SELECT ... FROM products p
LEFT JOIN product_keywords pk ON p.id = pk.product_id
GROUP BY p.id;
```

**影响**：
- 商品数量多时查询慢
- 数据库 CPU 占用高

## 优化措施

### 1. 后端搜索优化

#### 实现后端搜索接口
```javascript
// 前端改为调用搜索接口
export async function searchProducts(keyword: string): Promise<ProductType[]> {
  const response = await axios.get<ProductType[]>(
    `/api/products/search?q=${encodeURIComponent(keyword)}`
  );
  return response.data;
}
```

#### 使用全文索引
```sql
-- 创建全文索引
ALTER TABLE products ADD FULLTEXT INDEX idx_fulltext_name (name);
ALTER TABLE product_keywords ADD FULLTEXT INDEX idx_fulltext_keyword (keyword);

-- 使用全文搜索
SELECT DISTINCT p.* 
FROM products p
LEFT JOIN product_keywords pk ON p.id = pk.product_id
WHERE MATCH(p.name) AGAINST('shirt' IN NATURAL LANGUAGE MODE)
   OR MATCH(pk.keyword) AGAINST('shirt' IN NATURAL LANGUAGE MODE);
```

**优势**：
- 搜索速度提升 10-100 倍
- 支持相关度排序

#### 使用 Elasticsearch
```javascript
// 适合大型电商平台
const { Client } = require('@elastic/elasticsearch');
const client = new Client({ node: 'http://localhost:9200' });

async function searchProducts(keyword) {
  const { body } = await client.search({
    index: 'products',
    body: {
      query: {
        multi_match: {
          query: keyword,
          fields: ['name^2', 'keywords'], // name 权重更高
          fuzziness: 'AUTO' // 支持拼写错误
        }
      }
    }
  });
  
  return body.hits.hits.map(hit => hit._source);
}
```

**优势**：
- 毫秒级搜索响应
- 支持同义词、拼写纠错
- 搜索结果高亮

### 2. 分页加载

#### 后端实现分页
```javascript
// Controller
exports.getAllProducts = async (req, res) => {
  const page = parseInt(req.query.page) || 1;
  const limit = parseInt(req.query.limit) || 20;
  const offset = (page - 1) * limit;

// Model
static async findAll(limit, offset) {
  const query = `
    SELECT ... 
    FROM products p
    LEFT JOIN product_keywords pk ON p.id = pk.product_id
    GROUP BY p.id
    ORDER BY p.created_at DESC
    LIMIT ? OFFSET ?
  `;
  
  const [rows] = await db.query(query, [limit, offset]);
  return rows;
}
```

#### 前端实现无限滚动
```typescript
import { useEffect, useState, useRef } from 'react';

export function HomePage() {
  const [products, setProducts] = useState<ProductType[]>([]);
  const [page, setPage] = useState(1);
  const [hasMore, setHasMore] = useState(true);
  const [isLoading, setIsLoading] = useState(false);
  
  const observerRef = useRef<IntersectionObserver | null>(null);
  const loadMoreRef = useRef<HTMLDivElement | null>(null);

  const loadProducts = async (pageNum: number) => {
    setIsLoading(true);
    try {
      const response = await axios.get(
        `/api/products?page=${pageNum}&limit=20`
      );
      
      setProducts(prev => [...prev, ...response.data.data]);
      setHasMore(pageNum < response.data.pagination.totalPages);
    } catch (error) {
      console.error('Failed to load products:', error);
    } finally {
      setIsLoading(false);
    }
  };

  useEffect(() => {
    loadProducts(page);
  }, [page]);

  // 实现无限滚动
  useEffect(() => {
    if (observerRef.current) observerRef.current.disconnect();

    observerRef.current = new IntersectionObserver(entries => {
      if (entries[0].isIntersecting && hasMore && !isLoading) {
        setPage(prev => prev + 1);
      }
    });

    if (loadMoreRef.current) {
      observerRef.current.observe(loadMoreRef.current);
    }

    return () => {
      if (observerRef.current) observerRef.current.disconnect();
    };
  }, [hasMore, isLoading]);

  return (
    <div className="home-page">
      <ProductsGrid products={products} />
      {hasMore && (
        <div ref={loadMoreRef} className="load-more-trigger">
          {isLoading && <div>Loading more products...</div>}
        </div>
      )}
    </div>
  );
}
```

### 3. 缓存策略

```typescript
// 使用 React Query 实现缓存
import { useQuery } from '@tanstack/react-query';

export function HomePage() {
```

```javascript
const redis = require('redis');
const client = redis.createClient();

exports.getAllProducts = async (req, res) => {
  const cacheKey = 'products:all';
  
  // 先查缓存
  const cached = await client.get(cacheKey);
```

## 总结

### 最佳实践建议

#### 小型项目（< 1000 商品）
- ✅ 前端过滤搜索
- ✅ 一次性加载所有商品
- ✅ 简单的 MySQL 查询
- ✅ HTTP 缓存

#### 中型项目（1000-10000 商品）
- ✅ 后端搜索 + 前端分页
- ✅ Redis 缓存热门数据
- ✅ 添加数据库索引
- ✅ 图片 CDN

#### 大型项目（> 10000 商品）
- ✅ Elasticsearch 搜索
- ✅ 无限滚动 + 虚拟滚动
- ✅ 分布式缓存
- ✅ 微服务架构
- ✅ 服务端渲染（SSR）

### 技术选型考虑因素
1. **数据量**：决定是否需要分页、虚拟滚动
2. **搜索复杂度**：决定是否需要 Elasticsearch
3. **访问量**：决定缓存策略
4. **团队规模**：决定架构复杂度
5. **预算**：决定是否使用 CDN、云服务
